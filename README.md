# Trend Shorts Bot website

Public pages for the Trend Shorts Bot TikTok app, served at https://baileygs7.github.io/

- `index.html`: what the app does
- `privacy.html`, `terms.html`: Privacy Policy and Terms of Service linked from the TikTok developer app
- `callback.html`: the OAuth redirect URI. It shows the one-time code TikTok returns so it can be pasted into the "Connect TikTok" workflow.
